# SCGPC Fire Resistance Research Lab

Reference-oriented full-stack Flask website for:

Effect of Sugarcane Bagasse Ash (SCBA) on Fire Resistance of Fly Ash–GGBS Based SCGPC

## Features
- Visual research-lab dashboard
- Responsive mobile/desktop UI
- Super Admin / Editor / Common User roles
- 12 mixes, 4 temperatures, 3 replicates = 144 specimens
- Data entry, image upload and automatic calculations
- Graph builder with multiple analysis options
- Results and specimen status
- Notes
- Excel export
- Admin user management
- Render deployment configuration
